# Data

| Folder | Content | In Git |
| --- | --- | --- |
| `input/` | Your real input file | No, ignored |
| `samples/` | Small test inputs with a known answer (planted or checked by hand) | Yes |

**Rules**

- Real data only if your company allows it with Copilot; no personal data, no credentials.
- Samples are fictitious or fully anonymised, under 1 MB per file.
- File names: `<what>_<YYYY-MM>.csv`.
